# Tutorial: PDF to Narrated Video

This tutorial walks you through converting a PDF (e.g., an academic paper or slide deck) into a narrated video with AI-generated speech. You'll also learn how to interactively query the content.

## Prerequisites

- Node.js 20+
- ImageMagick (`magick` command)
- [Claude Code](https://claude.com/claude-code) (for the `/narrate` step)
- OpenAI API key (`OPENAI_API_KEY` environment variable)

```bash
# Install MulmoCast-Slides
npm install -g @mulmocast/slide

# Verify installation
mulmo-slide --help
```

## Setup

### 1. Create a project directory

```bash
mkdir my-narrate-project
cd my-narrate-project
```

### 2. Configure API keys

Create a `.env` file with your API keys:

```bash
cat <<'EOF' > .env
OPENAI_API_KEY=sk-your-openai-api-key
GEMINI_API_KEY=your-gemini-api-key
EOF
```

- `OPENAI_API_KEY`: Used for text-to-speech (TTS) and transcription
- `GEMINI_API_KEY`: Used for narration generation (within the `/narrate` skill)

### 3. Place your PDF file

Copy the PDF you want to convert into the project directory:

```bash
cp /path/to/your-paper.pdf .
```

### 4. Install Claude Code skills

```bash
mulmo-slide extend init
```

This copies the skill files to `.claude/skills/` in your project.

## Quick Start (Copy-Paste)

```bash
# In Claude Code, run:
/narrate your-paper.pdf
```

That's it! The `/narrate` skill automatically:
1. Converts the PDF to slide images
2. Extracts text from each page
3. Generates AI narration for each slide
4. Adds metadata (keywords, sections, context)
5. Validates the output
6. Shows you the next steps

## What `/narrate` Produces

```
scripts/your-paper/
  mulmo_script.json      # MulmoScript (images + empty text)
  extracted_texts.json    # Raw text extracted from each page
  extended_script.json   # ExtendedScript (narration + metadata)
  images/
    your-paper-0.png     # Page 1 as image
    your-paper-1.png     # Page 2 as image
    ...
```

## After `/narrate`: Next Steps

### Query the Content Interactively

Ask questions about your document:

```bash
npx mulmocast-preprocessor query scripts/your-paper/extended_script.json -i
```

Example session:
```
> What is the main topic of this paper?
The paper discusses challenges in LLM inference hardware...

> What are the four research directions?
1. High Bandwidth Flash (HBF)
2. Processing-Near-Memory (PNM)
3. 3D Compute-Logic Stacking
4. Low-latency Interconnect

> exit
```

Ask a single question:
```bash
npx mulmocast-preprocessor query scripts/your-paper/extended_script.json "What is HBF?"
```

Generate a summary:
```bash
npx mulmocast-preprocessor summarize scripts/your-paper/extended_script.json
```

### Generate a Narrated Video

Convert the ExtendedScript to a clean MulmoScript, then generate the video:

```bash
npx mulmocast-preprocessor scripts/your-paper/extended_script.json \
  -o scripts/your-paper/mulmo_script.json
npx mulmo movie scripts/your-paper/mulmo_script.json
```

Output: `output/mulmo_script_ja.mp4`

### Review and Iterate

Watch the video and check the narration quality. If you want to adjust:

1. Edit `scripts/your-paper/extended_script.json` directly (modify `text` fields)
2. Or re-run `/narrate` with instructions for adjustments
3. Re-run the video generation commands above

## Supported Formats

`/narrate` works with any format supported by MulmoCast-Slides:

```bash
/narrate your-paper.pdf       # Academic papers, documents
/narrate your-slides.pptx     # PowerPoint presentations
/narrate your-slides.md       # Marp markdown slides
/narrate your-slides.key      # Keynote (macOS only)
```

## Troubleshooting

### "Unrecognized key: scriptMeta" error when running `mulmo movie`

The preprocessor may not fully strip extended fields. Run this to clean up:

```bash
node -e "
const fs = require('fs');
const d = JSON.parse(fs.readFileSync('scripts/your-paper/mulmo_script.json', 'utf8'));
delete d.scriptMeta;
delete d.outputProfiles;
d.beats.forEach(b => { delete b.meta; delete b.variants; });
fs.writeFileSync('scripts/your-paper/mulmo_script.json', JSON.stringify(d, null, 2));
"
```

### Empty narration in video

Make sure you ran `/narrate` before generating the video. The PDF converter intentionally leaves `text` empty — narration is generated by the `/narrate` skill.

### ImageMagick not found

```bash
# macOS
brew install imagemagick

# Ubuntu/Debian
sudo apt-get install imagemagick
```
